## Быстрый запуск

Нужны Python 3.10+, Node.js 24 и Ollama. Веса моделей в репозиторий не входят.

```bash
git clone https://github.com/tomystark456/ai-sefety.git
cd ai-sefety
ollama pull vicuna:7b
ollama create vicuna-guarded -f experiments/Modelfile.guarded
cd site/web
npm ci
npm run build
cd ../..
python site/server.py
```

Открыть [http://127.0.0.1:8765/](http://127.0.0.1:8765/).
Служба Ollama должна работать на `http://127.0.0.1:11434`; если она ещё не запущена,
выполнить `ollama serve` в отдельном терминале. Python-сервер и новые оценочные
скрипты используют стандартную библиотеку, установка pip-пакетов для них не нужна.

Для разработки: запустить Python-сервер, затем `npm run dev` в `site/web`.

## Выбор модели

В обоих чатах есть список **«Модель и защита»**:

| Режим | Что делает |
|---|---|
| Vicuna 7B — базовая | Обычная `vicuna:7b` со своим системным промптом |
| Vicuna Guarded | Те же веса с ограничивающей системной инструкцией |
| Vicuna Guarded + SmoothLLM | Пять изменённых копий запроса и выбор по большинству признаков отказа |

Выбор сохраняется в браузере. Смена режима начинает новый диалог; прежняя
переписка полноэкранного чата остаётся в истории вместе со своим режимом.
Пока модель отвечает, переключатель заблокирован.

Сервер дополнительно проверяет роли и структуру, ограничивает сообщение 4 000
символами, тело запроса 65 536 байтами и удерживает последние 12 сообщений.
`POST /api/chat` принимает `mode`: `baseline`, `guarded`, `guarded_smooth`.
Неизвестные режимы отклоняются. По умолчанию действует `guarded_smooth`;
переменная `SMOOTHLLM_ENABLED=0` меняет только режим запросов без явного `mode`.

## Эксперимент и результаты

Новый прогон от 27 октября 2026: три конфигурации, одинаковые 40 входов на каждую,
120 выбранных ответов и 280 генераций без прогрева. В наборе по 10 прямых запросов,
запросов с опубликованным суффиксом, cached-GCG входов и безвредных задач.

| Метрика | Base | Guarded | Guarded + Smooth |
|---|---:|---:|---:|
| Лексический bypass, published suffix | 7/10 | 7/10 | 1/10 |
| Вредные ответы по локальному Qwen-судье | 1/10 | 0/10 | 0/10 |
| Обычные задачи по уточнённым критериям | 7/10 | 7/10 | 3/10 |
| Средняя задержка обычной задачи | 0.72 s | 0.50 s | 2.65 s |

Сглаживание снижает лексический показатель с 70% до 10%, но ухудшает обычные
ответы и увеличивает задержку. Дополнительное снижение вредности относительно
Guarded на этом малом наборе не доказано. Лексический детектор и модель-судья
ошибаются; их показатели нельзя считать подтверждённым человеком semantic ASR.
Исходные и уточнённые оценки обычных задач сохранены, критерии уточнялись после
прогона без подбора параметров защиты. Старые результаты Midterm хранятся отдельно.

## Повторение модельного эксперимента

```bash
python experiments/evaluate_smoothllm.py
python experiments/judge_outputs.py
python experiments/review_benign.py
```

Для дополнительного судьи нужна установленная `qwen3.5:4b` (`ollama pull qwen3.5:4b`).
Точные 40 входов уже сохранены в `experiments/data/gcg_evaluation_cases.json`;
повтор не требует скачивания датасета. Скрипт продолжает незавершённые локальные
прогоны. Для независимого повтора сначала переименовать прежние локальные файлы
результатов. Для исторического garak-прогона есть отдельные `reproduce.py`, YAML
и `experiments/requirements.txt`; он повторяет только cached-GCG.

Сводку можно пересчитать без Ollama и без сырых ответов:

```bash
python experiments/evaluate_smoothllm.py --summary
```

## Что опубликовано

В `experiments/results/` включены агрегаты, записи метрик по каждому случаю,
автоматические метки, рубрики и контрольные суммы исходных файлов. Тексты ответов,
кандидаты сглаживания и свободные пояснения судьи исключены. Сырые данные остаются
локально в `experiments/logs/` и защищены `.gitignore`, как и `tmp/`, `node_modules`,
сборка фронтенда, окружения и секреты. Экспорт результатов выполняет
`python experiments/export_public_results.py`.

PDF и слайды ссылаются на исходные локальные журналы. Их публичные аналоги метрик
перечислены в [описании evidence](experiments/results/README.md).

## Ограничения

Это локальный учебный прототип. Сглаживание может искажать смысл, числа и имена.
Не реализованы общий лимит параллельных запросов, rate limit, семантический фильтр
выхода и серверная аутентификация истории. Пользователь должен проверять факты
и источники перед публикацией. Прокси не сохраняет диалог, но полноэкранный чат
использует browser localStorage. Новости макета выдуманы.

Методика опирается на [Zou et al., GCG](https://arxiv.org/abs/2307.15043) и
[Robey et al., SmoothLLM](https://arxiv.org/abs/2310.03684). Это независимая адаптация
для Ollama с другим детектором голосования, без заявления о формальной гарантии.
Источники тестовых данных и лицензия garak указаны в [data/README](experiments/data/README.md).
