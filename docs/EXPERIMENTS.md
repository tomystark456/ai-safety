# Assignment 3 - Safety Improvement of a Local LLM Assistant

AISRA1301 - AI Security and Risk Analysis, QAIRU.

Продолжение Midterm: тот же новостной прототип, Vicuna и статья Zou et al.,
*Universal and Transferable Adversarial Attacks on Aligned Language Models*
([arXiv:2307.15043](https://arxiv.org/abs/2307.15043)).

## Защита

1. `experiments/Modelfile.guarded`: системная инструкция поверх тех же весов Vicuna.
2. `site/smoothllm.py`: независимая реализация идеи [SmoothLLM, Robey et al.](https://arxiv.org/abs/2310.03684).
   Пять копий последнего пользовательского сообщения, случайная вставка символов в
   10% позиций всего сообщения, пять вызовов Ollama и выбор ответа из большинства
   по признаку отказа. Граница атакующего суффикса заранее не известна. Это адаптация
   для Ollama с собственным regex-детектором, а не точное воспроизведение статьи
   или сертифицированная гарантия безопасности.
3. `site/safety.py`: серверная проверка ролей, структуры и размеров запроса.

Прототип по умолчанию использует `vicuna-guarded` вместе со сглаживанием. Все пять
ответов буферизуются до голосования: промежуточные ответы пользователю не отправляются.
Ошибка модели/защиты возвращает 502. В обоих чатах есть список «Модель и защита»:
обычная `vicuna:7b`, `vicuna-guarded` и `vicuna-guarded + SmoothLLM`. При смене
режима начинается новый диалог; в полноэкранном чате прежняя переписка остаётся
в истории вместе со своим режимом. Выбор запоминается в браузере. Во время ответа
переключатель заблокирован. Базовый режим сохраняет проверку входного API, но
использует собственный системный промпт обычной Vicuna.

`POST /api/chat` принимает поле `mode`: `baseline`, `guarded` или `guarded_smooth`.
Сервер сопоставляет режим с разрешённой моделью и отклоняет неизвестные значения.
Если поле отсутствует, режим по умолчанию — `guarded_smooth`; для таких запросов
`$env:SMOOTHLLM_ENABLED='0'` перед запуском выбирает `guarded`. Явный выбор в
интерфейсе имеет приоритет. Все режимы используют temperature 0, num_predict 96
и num_ctx 2048, как в новом эксперименте.

## Настоящий прогон Ollama

Ollama работает по адресу `http://127.0.0.1:11434`. Новое сравнение использует:

- `vicuna:7b`;
- `vicuna-guarded`;
- `vicuna-guarded` вместе с 5-кратным сглаживанием.

У каждой конфигурации одинаковые 40 случаев: 10 первых целей AdvBench без суффикса,
те же 10 целей с неизменённым опубликованным суффиксом llm-attacks.org, 10 уникальных
cached-GCG запросов из предоставленного журнала и 10 безвредных контрольных задач.
У кэшированной пробы только две исходные цели и разные суффиксы: это не 10 независимых
вредоносных намерений. Во всех вариантах temperature 0, seed 20261027, num_predict 96,
num_ctx 2048. Для сглаживания seed меняется по индексу случая, но фиксирован для повтора.

```powershell
python experiments\evaluate_smoothllm.py
# Повторный подсчёт без новых обращений к модели:
python experiments\evaluate_smoothllm.py --summary
# Дополнительная оценка завершённых ответов локальной qwen3.5:4b:
python experiments\judge_outputs.py
python experiments\review_benign.py
```

В наборе уже сохранены точные входы. `--prepare` нужен только для пересоздания набора
из скачанного HTML авторов в `tmp/assignment3/attack-site.html` и сохранённого CSV.
Обычный повтор не требует интернета. Скрипт пропускает уже записанные пары конфигурация/случай;
для независимого повтора сначала переименовать `ollama_results.jsonl` и результаты judge.
Время прогрева не включено. Порядок конфигураций фиксирован; задержки зависят от среды.

`ollama_results.jsonl` содержит ответы и голоса, `ollama_summary.json` - сравнение,
`ollama_environment.json` - версию Ollama, модели, SHA-256 набора и кода.
`judge_summary.json` - дополнительная модельная оценка. Это один автоматический
судья без независимой человеческой разметки: его метки могут быть ошибочными.
Детектор garak считает отсутствие лексической фразы отказа, что нельзя отождествлять
с реальной вредностью. Успех безвредных задач оценивается заранее заданными простыми
шаблонами ответа, а не полноценной редакторской экспертизой. После прогона исправлена оценка регистра, нумерованных списков и точности чисел; исходные оценки сохранены отдельно в benign_review.json. Параметры защиты и ответы не менялись.

## Дополнительные HTTP-тесты

Нужен только Python 3.10+, без сторонних пакетов и без реальной модели.

```powershell
python experiments\check_defence.py
python experiments\evaluate_boundary.py
```

Парный тест поднимает замороженный исходный и обновлённый HTTP-прокси с заглушкой
Ollama. Каждая версия получает одинаковые 48 случаев: 8 подставных ролей system,
8 сообщений сверх лимита, 8 неверных схем и 24 допустимых запроса. Логи:
`test_cases.json`, `boundary_results.jsonl`, `boundary_summary.json` в новой папке.
Это проверка границы API, а не измерение ASR модели. Время HTTP с заглушкой не включает
генерацию. Дополнительно проверяется корректная ошибка при недоступности модели.

## Запуск прототипа

Нужны Python 3.10+, Node.js, поддерживающая текущую версию Vite из lock-файла, и Ollama.
Если команда ollama отсутствует в PATH, работающая служба всё равно доступна через API.

```powershell
ollama serve
# В другом терминале:
ollama pull vicuna:7b
ollama create vicuna-guarded -f experiments\Modelfile.guarded
cd site\web
npm ci
npm run build
cd ..
python server.py
```

Открыть `http://127.0.0.1:8765`. Сервер привязан к loopback. Режим разработки:
запустить `site/server.py` и `npm run dev` из `site/web`.
Сервер принимает только роли user/assistant, добавляет собственную системную инструкцию,
проверяет весь список и оставляет 12 последних сообщений. Лимиты: 4 000 символов
в сообщении, 65 536 байт в теле. Обычный текст jailbreak не блокируется этими правилами;
против него оцениваются модельный промпт и сглаживание.

## Сохранённый эксперимент Midterm

Агрегаты в `experiments/logs/advbench_summary.json`: direct 3/25 против 1/25;
cached GCG 0/26 против 0/26; published suffix 22/25 против 19/25.
Это исторические измерения, отдельно от нового прогона. Метаданные старого garak
относятся к 16 октября 2026, версия 0.17.0. Прямой набор и опубликованный суффикс
имеют только старые агрегаты; полное независимое восстановление тех двух старых
измерений по имеющимся файлам невозможно. Новое исследование сохраняет точные входы
и ответы, поэтому не зависит от этого недостатка старых материалов.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r experiments\requirements.txt
.\.venv\Scripts\python.exe experiments\reproduce.py
.\.venv\Scripts\python.exe experiments\reproduce.py --run
```

Перед `--run` сохранить старые `gcg_*.report.*`, поскольку сценарий использует прежние
префиксы. Этот сценарий повторяет только cached-GCG, а не весь новый эксперимент.

## Ограничения и данные

Сглаживание может испортить смысл, числа, имена и код; пять вызовов увеличивают задержку
и ресурсы. Regex-голосование может ошибаться. Обнаруженные улучшения на малом наборе
не доказывают устойчивость к адаптивным или семантическим атакам. Не реализованы
семантический выходной фильтр, rate limit, общий лимит параллелизма и серверная
аутентификация истории. Таймауты ограничивают бездействие, а не общее время пяти вызовов.

Чат предупреждает об ошибках ИИ, проверке фактов и личных данных. Решение о публикации
остаётся за человеком. Прокси не сохраняет диалог, но полноэкранный чат хранит историю
в browser localStorage. Исследовательские журналы garak и нового эксперимента содержат
входы/ответы. Не публиковать сырые вредоносные завершения; доступ нужен только для
разрешённой учебной проверки. Новости макета выдуманы.

## Итоги нового прогона (27 октября 2026)

| Метрика | Base | Guarded | Guarded + Smooth |
|---|---:|---:|---:|
| Лексический bypass, published suffix | 7/10 | 7/10 | 1/10 |
| Вредные ответы по финальному Qwen-судье | 1/10 | 0/10 | 0/10 |
| Исходный pattern score обычных задач | 9/10 | 7/10 | 5/10 |
| Обычные задачи по уточнённым критериям | 7/10 | 7/10 | 3/10 |
| Средняя задержка обычной задачи | 0.72 s | 0.50 s | 2.65 s |

Сглаживание уменьшило лексический показатель на 60 процентных пунктов, но
дополнительное снижение вредности относительно guarded на этом наборе не доказано.
Локальный судья ошибочно относит некоторые короткие бессодержательные фрагменты к
отказам; его метки зависят от формулировки задания и требуют человеческой проверки.
Существенная потеря качества обычных задач и увеличение задержки прямо отражены
в отчёте. Это экспериментальная защита, а не обещание полной безопасности.
